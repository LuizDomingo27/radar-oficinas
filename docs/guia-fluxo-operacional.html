Guia do fluxo operacional

O que o Radar de Oficinas faz, quem opera, o que entra, o que sai e o que acontece quando algo dá errado. Este guia descreve o único fluxo com escrita do sistema: Atualizar dados — a substituição das planilhas de origem pelos números publicados no dashboard.

Propósito

As áreas de Produção, RH e Qualidade mantêm suas planilhas em Excel. O Radar consolida essas planilhas num único painel comparável entre oficinas — ranking, ficha individual, impacto de treinamentos e qualidade — para que a decisão sobre onde atuar não dependa de abrir sete arquivos diferentes.

O sistema não digita nem edita dado de origem: ele apenas lê as planilhas, calcula os indicadores e publica o resultado. A fonte da verdade continua sendo o Excel de cada área.

Papéis e tela

PapelO que faz
Analista de dados (operador) Reúne as planilhas do mês, envia pelo painel e confirma a mensagem de resultado. É o único papel que escreve no sistema.
Gestor / supervisão Consulta o dashboard. Somente leitura.

Tela usada

Barra lateral do app, bloco Atualizar dados: um campo Planilhas (.xlsx) (aceita vários arquivos) e o botão Atualizar dados. O dashboard ocupa a área principal.

O nome do arquivo não precisa estar exato

O envio é reconhecido por palavras-chave no nome. “estoque jeans agosto.xlsx” e “Indicador geral_Julho.xlsx” são aceitos e salvos com o nome que o processamento espera. Um arquivo que não casa com nenhuma regra é guardado como veio e aparece na lista do que ainda falta.

A aba pode ter sido renomeada

Quando uma planilha é reexportada, o Excel costuma renomear a aba (foi o que aconteceu com POSTOS: a aba Dados virou Planilha1). O sistema procura a aba primeiro pelo nome e, se não achar, pelo cabeçalho — a aba cujos títulos de coluna são os esperados. Se duas abas ou nenhuma casarem, a atualização para e informa quais abas existem no arquivo, em vez de ler a aba errada e publicar número inventado.

Fluxo completo, do envio ao painel

  1. Selecionar as planilhas. Juntas ou uma por vez — os envios se acumulam na sessão até completar as sete.
  2. Clicar em Atualizar dados. Sem nenhum arquivo selecionado, o sistema avisa e não faz nada.
  3. Gravação. Cada arquivo é salvo com o nome canônico na pasta de onde o processamento lê. Um envio novo substitui o anterior.
  4. Processamento (6 passos). De-Para de nomes → Fatos → Métricas → Impacto → Dashboard → Qualidade.
  5. Conferência do que falta. O sistema lista as bases ausentes para o painel completo.
  6. Publicação. Com o processamento concluído, os arquivos de resultado são gravados no repositório (GitHub) para persistirem entre reinícios.
  7. Recarga. A página recarrega já com os números novos e a mensagem do resultado.

Decisões e mensagens

SituaçãoMensagemO que foi salvo
Todas as bases presentes, processamento e publicação concluídos verde Pipeline completo atualizado Todos os indicadores + publicação no repositório
Processou, mas a publicação falhou (token sem permissão de escrita) amarelo Atualizado, com falha ao publicar Indicadores na sessão atual; não persiste após reinício
Faltam bases (envio incremental em andamento) informativo Recebido; ainda faltam … Os arquivos enviados ficam guardados aguardando os demais
Só o Indicador geral está disponível amarelo Apenas a Qualidade foi atualizada Somente os indicadores de qualidade
Todas as bases presentes, mas uma planilha está inconsistente vermelho Falha ao atualizar, com o motivo Nada é alterado — os números anteriores continuam no ar

A mensagem de erro traz a causa (“Aba X não existe em POSTOS.xlsx…”, “Planilha não encontrada…”), não apenas em que passo parou. É a informação que permite ao operador corrigir o arquivo e reenviar.

Exceções previstas

ExceçãoComportamento
Nenhum arquivo selecionadoAviso; nada é processado
Arquivo com nome fora do padrão Reconhecido por palavras-chave; se não casar, entra como base faltante
Aba renomeada na reexportação Reencontrada pelo cabeçalho; segue o processamento
Aba ambígua ou ausente Para com erro nomeando as abas do arquivo; nada é publicado
Arquivo corrompido ou não-xlsx Erro identificando o arquivo; nada é publicado
Coluna oficial de eficiência ausente Erro explícito — o sistema não estima o valor por posição
Credencial de publicação ausente ou sem permissão Indicadores atualizados na sessão, alerta de que não persistiu
Nome de oficina divergente entre planilhas Resolvido pelo De-Para; o que não resolve fica registrado à parte

O que o sistema salva

SaídaConteúdo
data/dashboard.json Ranking, ficha por oficina, séries e impacto — o que a tela lê
data/qualidade.json Nota de qualidade, 2ª qualidade e principais causas
data/fato_*.json, data/metricas_*.json Etapas intermediárias, para auditoria e reprocessamento

As planilhas de origem não são versionadas — só os resultados, que são leves. No ambiente de nuvem o disco é temporário: sem a publicação no repositório, o envio vale apenas para a sessão atual.
